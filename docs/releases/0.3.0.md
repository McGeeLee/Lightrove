# Lightrove 0.3.0 · 拾光

本次更新优化后台增量索引与存储占用，并加入视频 OCR 开关和 Android 实时进度通知。

## 更新内容

- **增量索引与中断恢复**：跳过未变化且已完成的媒体，处理新增、修改、失败和中断的项目；长视频分阶段保存，恢复时复用已完成的视觉和声音向量，减少重复推理与数据库写入。
- **减少索引体积**：768 维向量改用 int8 存储，单个向量从 3,072 字节降至 780 字节，减少约 74.6%。旧索引会后台分批转换并回收空闲空间，无需重新运行模型；实际总空间降幅取决于图库内容。
- **视频 OCR 开关**：设置中新增“视频文字识别”，默认关闭，下一次索引生效。图片 OCR 保持开启；视频画面和声音语义索引继续保留。关闭后再次更新索引会清理已有视频 OCR 文字及对应向量，再次开启可补建文字索引。
- **Android 实时进度通知**：Android 16 及以上支持系统实时进度通知，显示进度并可停止任务；是否提升显示取决于系统和用户设置。旧版保留普通进度通知，锁屏公开内容隐藏文件名。
- **索引期间搜索刷新**：新完成的视觉和声音索引可更新当前搜索结果，复用查询向量并减少重复搜索。

## 安装与升级

- 支持 Android 12 及以上，版本号 **0.3.0**，versionCode **3**。
- 下载 `lightrove-0.3.0.apk` 直接安装；`lightrove-0.3.0.aab` 用于应用商店分发。
- 使用与 0.2.0 相同的正式签名，可覆盖安装已有正式版并保留本地数据；数据库自动迁移。
- 通过“更新索引”触发增量处理。当前显示进度和处理阶段，尚未提供预计剩余时间。

## 验证

- 43 项 JVM 测试、47 项 API 37 设备测试通过，包含真实模型推理、旧库迁移、索引恢复、设置和六语种界面。
- 640 个向量的存储测试中，数据库与 WAL 合计从 2,715,648 字节降至 741,376 字节，减少约 72.7%。量化保留 768 维，接近的语义分数仍可能改变排序。
- 真机耗电、长时间后台任务和各厂商实时通知显示仍需更多设备验证。
