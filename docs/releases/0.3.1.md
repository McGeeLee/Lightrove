# Lightrove 0.3.1

## Fixes

- Fixed OCR failing for every selected item in minified release builds: retain the public constructors used by ML Kit component discovery.
- Save completed OCR scripts, including empty reads, and retry only missing scripts. Decode only video frames with unfinished OCR or image embeddings.
- Reuse completed soundtracks, including silent and no-audio videos. Resume interrupted audio from the last contiguous completed window, replaying its overlap.
- Retain usable text and vectors after partial failures; show the failing stage and SDK cause. Pause repeated shared OCR/inference errors instead of applying them to the entire library.
- Preserve existing indexes through a Room 1/2 → 3 migration; no model re-download is needed. Older interrupted indexes may need one pass to record stages they did not previously track.

## Search

- Add a persistent Relevance threshold setting, default 0.45, adjustable from 0 to 1. Higher values filter more weak semantic matches; direct text matches are retained.
- Refresh the active search using its cached query vector when the threshold changes. Results remain ordered by relevance.
- Localize the control in all six app languages and support large text and accessibility announcements.

## Validation

See [verification record](../VERIFICATION.md) for build, migration, device and minified-release OCR checks. The threshold is an engineering default, not a calibrated confidence score or a retrieval-quality benchmark.
